# 网盘配置教程(与 OpenList v4.2.9 驱动一一对应)

本项目的网盘配置全部在 **`storages.json`** 里:每一行 = 一个网盘,`driver` 必须是 OpenList 的**注册驱动名**(区分大小写),`fields` 是该驱动的字段。凭证一律写 `env:SECRET名`,真实值放 GitHub Secrets。

> 三个铁律(都是踩过坑的):
> 1. **驱动名以本文为准**——`迅雷`是 `Thunder` 不是 Xunlei,`天翼`是 `189Cloud` 不是 Cloud189,`115`是 `115 Cloud` 不是 115;
> 2. **字段全部显式写全**,不要依赖 OpenList 网页表单的默认值——本项目通过 API 创建存储,默认值不会自动补(百度曾因 `root_folder_path` 为空导致列目录永远为空);
> 3. 配好后先跑一次 `list` 模式验证,飞书收到目录清单才算成功。

通用取 cookie 方法(夸克/UC/115):Chrome/Edge 登录网盘网页版 → 按 `F12` → 顶部「网络/Network」→ 刷新页面 → 点第一条请求 → 「请求标头」里找到 `Cookie:` → **复制整串值**(不要只复制某个字段)。

## 1. 百度网盘(驱动 `BaiduNetdisk`)✅ 已验证可用

- **登录方式**:OAuth 令牌(不是账号密码,也不是 BDUSS)
- **获取**:
  1. 打开 [OpenList Token 工具](https://api.oplist.org) → 选「百度网盘」→ 保持"使用 OpenList 提供的参数" → 点授权 → 登录百度账号
  2. 复制页面上的**刷新令牌(Refresh Token)**
- **Secret**:`BAIDU_REFRESH_TOKEN` = 刷新令牌
- **storages.json 条目**:

```json
{ "mount_path": "/baidu", "driver": "BaiduNetdisk", "fields": {
  "refresh_token": "env:BAIDU_REFRESH_TOKEN",
  "root_folder_path": "/",
  "order_by": "name", "order_direction": "asc",
  "download_api": "official", "use_online_api": false,
  "client_id": "NqOMXF6XGhGRIGemsQ9nG0Na",
  "client_secret": "SVT6xpMdLcx6v4aCR4wT8BBOTbzFO8LM"
} }
```

- **注意**:刷新令牌是一次性的,每次运行后系统会**自动把新令牌回写 Secret**(需 `REPO_PAT`);`download_api` 可改 `crack`/`crack_video`(非官方通道,部分账号更快,稳定性自负)
- **常见错**:`errno: 2` = 字段没写全(尤其 `root_folder_path`);`refresh token has been used` = 回写失败,重新授权一次

## 2. 阿里云盘(驱动 `AliyundriveOpen`)

- **获取**:同一个 [OpenList Token 工具](https://api.oplist.org) → 选「阿里云盘 Open」→ 授权 → 复制**刷新令牌**
- **Secret**:`ALIYUN_REFRESH_TOKEN`
- **storages.json 条目**:

```json
{ "mount_path": "/aliyun", "driver": "AliyundriveOpen", "fields": {
  "refresh_token": "env:ALIYUN_REFRESH_TOKEN",
  "drive_type": "default", "alipan_type": "default",
  "remove_way": "trash", "use_online_api": true
} }
```

- **注意**:刷新令牌同样一次性 + 自动回写;`drive_type` 可改 `resource`(资源盘)/`backup`(备份盘)
- **速度**:阿里是几个网盘里最快的,推荐优先配

## 3. 夸克网盘(驱动 `Quark`)

- **获取**:登录 [pan.quark.cn](https://pan.quark.cn) → F12 → 网络 → 任选一条 `pan.quark.cn` 的请求 → 复制请求头里**整段 Cookie**
- **Secret**:`QUARK_COOKIE`
- **storages.json 条目**:

```json
{ "mount_path": "/quark", "driver": "Quark", "fields": { "cookie": "env:QUARK_COOKIE" } }
```

- **注意**:cookie 一般几周~数月有效,失效就重新取一次更新 Secret;夸克非会员有下载频率限制

## 4. UC 网盘(驱动 `UC`)

与夸克同族,字段完全一样:

```json
{ "mount_path": "/uc", "driver": "UC", "fields": { "cookie": "env:UC_COOKIE" } }
```

- **获取**:登录 UC 网盘网页版 → 同夸克方法取整段 Cookie → Secret `UC_COOKIE`

## 5. 天翼云盘(驱动 `189Cloud`)——账号密码登录

```json
{ "mount_path": "/cloud189", "driver": "189Cloud", "fields": {
  "username": "env:CLOUD189_USER", "password": "env:CLOUD189_PASS"
} }
```

- **Secret**:`CLOUD189_USER` = 手机号,`CLOUD189_PASS` = 密码
- **注意**:登录遇到验证码时,驱动支持加 `cookie` 字段(网页版 F12 取);天翼对机房 IP 风控一般,失败可重跑

## 6. 迅雷云盘(驱动 `Thunder`)——账号密码登录

```json
{ "mount_path": "/xunlei", "driver": "Thunder", "fields": {
  "username": "env:XUNLEI_USER", "password": "env:XUNLEI_PASS"
} }
```

- **Secret**:`XUNLEI_USER` / `XUNLEI_PASS`
- **注意**:驱动名是 `Thunder`(迅雷国际版叫别的);另有 `ThunderExpert` 等高级驱动,普通账号用 `Thunder` 即可

```json
{ "mount_path": "/123pan", "driver": "123Pan", "fields": {
  "username": "env:PAN123_USER", "password": "env:PAN123_PASS", "platform": "web"
} }
```

- **Secret**:`PAN123_USER` / `PAN123_PASS`
- **速度**:123 对非会员也很友好,推荐

## 8. 115 网盘(驱动 `115 Cloud`)——cookie 登录

```json
{ "mount_path": "/115", "driver": "115 Cloud", "fields": {
  "cookie": "env:PAN115_COOKIE", "page_size": "1000", "limit_rate": "2"
} }
```

- **获取**:登录 [115.com](https://115.com) → F12 取整段 Cookie → Secret `PAN115_COOKIE`
- **注意**:`limit_rate: 2` 是驱动要求的接口限速,别删,删了容易被 115 风控

## 9. 蓝奏云(驱动 `Lanzou`)——账号密码登录

```json
{ "mount_path": "/lanzou", "driver": "Lanzou", "fields": {
  "type": "account", "account": "env:LANZOU_USER", "password": "env:LANZOU_PASS",
  "baseUrl": "https://pc.woozooo.com", "shareUrl": "https://pan.lanzoui.com"
} }
```

- **Secret**:`LANZOU_USER` / `LANZOU_PASS`
- **注意**:`type` 有 `account`/`cookie`/`url` 三种模式,上面是账密模式;`baseUrl`/`shareUrl` 是必需字段(官方默认值),别删

## 配置一个新网盘的完整流程

1. 在 `storages.json` 加一行(从上面复制对应条目改挂载名即可)
2. 仓库 → Settings → Secrets → 添加对应的 Secret(名字必须和 `env:` 后面一致)
3. 提交推送到仓库
4. Actions → 网盘下载 → Run workflow → 模式 `list`、网盘选它、子路径留空 → 跑
5. 飞书收到目录清单 = 配置成功;失败看 Actions 日志:
   - `挂载 xxx 失败: ... 可用驱动名: ...` → 驱动名拼错,日志里列了全部合法名
   - `字段 xxx` 相关报错 → 字段名不对,对照本文或 [doc.oplist.org](https://doc.oplist.org)
   - 列目录为空 → 检查是否漏了 `root_folder_path` 之类的必需字段

## 字段速查(源自 OpenList v4.2.9 源码, drivers/*/meta.go)

| 驱动名 | 必填字段 | 可选/建议显式字段 |
|---|---|---|
| `BaiduNetdisk` | refresh_token | root_folder_path, order_by, order_direction, download_api, use_online_api, client_id, client_secret |
| `AliyundriveOpen` | refresh_token | drive_type, alipan_type, remove_way, use_online_api |
| `Quark` / `UC` | cookie | use_transcoding_address, only_list_video_file |
| `189Cloud` | username, password | cookie(验证码时) |
| `Thunder` | username, password | captcha_token, credit_key |
| `123Pan` | username, password | platform, UploadThread |
| `115 Cloud` | cookie | page_size, limit_rate |
| `Lanzou` | type 模式对应 | baseUrl, shareUrl, user_agent |
